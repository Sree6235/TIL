# How to Set and Verify Global Git Identity

When setting up Git on a new machine or switching away from a shared/startup account, verify and update the local identity so commits link to the right GitHub profile.

### Check Current Config
```bash
git config --global user.name
git config --global user.email```
### Update Name and Email
```bash
git config --global user.name "Sree6235"
git config --global user.email "sreelesha949@gmail.com"
